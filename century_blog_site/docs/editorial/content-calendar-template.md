## Pre-publication checks

- Source list attached
- Metadata drafted
- Category confirmed
- Internal links planned
- Visual plan approved
- Risk review completed if sensitive

## Post-publication checks

- Page loaded correctly
- Canonical correct
- Sitemap expected to include published URL
- Social preview acceptable
- Follow-up update needed?
