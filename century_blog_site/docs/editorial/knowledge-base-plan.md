# Century Blog Knowledge Base Plan

## Purpose

The knowledge base supports faster, more accurate editorial work by keeping reusable topic context, institution lists, source collections, misinformation risks, and update schedules in one place.

## Folder

`/content/knowledge-base/`

## What belongs in the knowledge base

- Topic primers
- Institution lists
- Reliable source libraries
- Common timelines
- Recurring explainer notes
- Citation formats
- Known misinformation patterns

## What does not belong

- Unverified rumours
- Unsourced statistics
- Copy-pasted third-party articles
- Claims without dates or attribution

## File maintenance rules

- Use placeholders where facts still need reporting
- Add dates to every verified note
- Link to original sources where possible
- Mark update frequency clearly
- Review high-risk topic files monthly

## Suggested maintenance ownership

- Nigeria and politics: standards or news desk
- Business and economy: business editor
- Health and science: standards editor
- Technology and AI: tech editor
- Source library and citations: copy desk or standards

## Knowledge base workflow

1. Create topic file
2. Add verified background only
3. Add recurring institutions and source links
4. Add misinformation risks
5. Add suggested internal links
6. Review on schedule
